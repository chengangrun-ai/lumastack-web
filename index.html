三步，从字幕到动效层

不需要先学软件，也不需要准备任何素材就能试。

1

导入或载入示例

点开工作台就有一份示例工程。也可以导入自己的 SRT 字幕，或者直接点「载入 28 秒示例」看完整编排。

2

时间轴上点一下，右侧出现这张卡的全部字段。改完画布立刻跟着变，空格播放看整体节奏，体检器会提醒快闪和空白段。

导出逐帧透明 PNG 序列或预览 WebM，拖进剪映置顶轨道。工程 JSON 留着，下期换个稿子接着用。

常见问题

先把话说清楚

要注册或者登录吗？

不用。打开网页直接进工作台，没有账号、没有试用额度，也没有把工程传到别处。

我的视频和图片会被上传吗？

不会。上传的素材只在本机浏览器里用 blob 地址引用，工程存 localStorage，导出也是本地下载。关掉页面，东西还在这台电脑上。

导出的透明层能直接进剪映吗？

逐帧 PNG 序列带透明通道，导进剪映或任何剪辑软件作为置顶轨道即可。预览 WebM 用来先看效果，正式成片建议在剪辑软件里合成。

和让大模型现场改动效有什么区别？

大模型现场生成是重新抽一次，改个颜色可能把布局也带跑。这里卡片是提前做好的，改动只落在你选中的那张卡上，改哪变哪，而且不花 token。

26 张卡和 27 组场景是哪来的？

动效卡来自 overlay studio 开源版的 20 张，加上社区扩展 6 张。科技场景来自 MotionGit 385712 的 0.2.7 开源模板包，B1 到 B4 已用 Canvas 等价重建，其余保留原版场景结构说明。

MotionGit 官网上那些竖屏和人脸居中功能有吗？

官网个人包里的竖屏、人脸自动居中、素材 API 需要登录和私有接口，这一版没有搬。公开开源能拿到的部分都在，功能清单在设置页里逐项列着。

换电脑了工程怎么办？

点顶栏「保存工程」下载一份 JSON，新电脑打开工作台用「导入」读回来就行。JSON 可以手改、可以 diff、可以进版本库。

为什么有的按钮叫「看说明」而不是「加入工程」？

原版 23 组原生单元依赖私有媒体素材与 Python 合成引擎，这一版把它们的场景结构和字段数如实列出来，不做假装能用的空壳。B1 到 B4 是可以直接加进工程的。
